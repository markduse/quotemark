- "We provide this list of the most commonly prescribed medications for declinable conditions to help you when you're completing applications."

- "If you aren't sure whether or not a medication is unacceptable, please contact the Underwriting Department."

- "lower case: generic name / Upper Case: brand name."
- "X: Indicates that the medication is unacceptable for a product. If there are no conditions listed next to the medication, the medication is always unacceptable for a product. If there are conditions listed next to the medication, the medication is unacceptable for a product when prescribed for any of the listed conditions."
- "NOTE: There are duplicate listings of several drugs. For some products, the medication is always unacceptable, and for others it's unacceptable when prescribed for any of the listed conditions."

**Key structural facts:**
- **There are NO lookback windows anywhere in this guide.** Outcomes key entirely off *current prescriptions* — no "within 2 years" / "within 12 months" language exists in the drug list.
- The only quantity-based rules are **dose thresholds on loop diuretics** (see Heart section) and "unit limits vary by product, see application" flags on insulin, Lantus, Novolog, Afrezza (pp.4, 24, 26, 30).
- No drug-combination rules appear in this document (combination logic, e.g., diabetes med combos, is not in this guide).

## 4. Accendo vs. Protection Series — how the guide distinguishes

Yes, the guide distinguishes outcomes per product in every row (six columns). Systematic differences:

1. **COPD meds:** hit ONLY Accendo Preferred. Not marked for Accendo Standard/Modified nor ANY Protection Series column (exception: promethazine for emphysema/COPD also X FE-Level, p.36).
2. **CHF meds:** decline ALL three Accendo plans; Protection Series mostly unaffected except Coreg/carvedilol/Lasix (X FE-Level), Entresto/sacubitril+valsartan any use (X FE-Level), loop diuretics for kidney failure/cirrhosis/CHF (X FE-Level + Graded), and loop-diuretic dose thresholds (X FE-Level).
3. **Angina/cardiomyopathy meds:** Accendo Preferred + Standard only (Accendo Modified OK). Protection Series instead flags "heart or artery disease" / "heart rhythm disorder" meds (amiodarone family, antiplatelets, DOACs) at FE-Level only.
4. **Cancer meds:** all three Accendo plans decline + usually FE-Level; aggressive/newer agents also FE-Graded; FE-Modified almost never blocked (so a Modified Protection Series plan remains the fallback for active cancer). Reverse quirk: Megace/megestrol blocks ONLY the three Protection Series plans, not Accendo (pp.27–28).
5. **Oxygen:** blocks everything, both product lines (p.32).
